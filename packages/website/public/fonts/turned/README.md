Fonts are self-hosted so the game makes no external font requests.

Barlow Condensed (600 and 800) and DM Sans (variable) originate from the Google Fonts repository, licensed under the SIL Open Font License included here. These subsets contain Latin and general punctuation.

Sources:
- https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- https://github.com/google/fonts/tree/main/ofl/dmsans
